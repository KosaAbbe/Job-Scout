# Job-Scout
A command line tool that analyses job postings and shows what employers actually want: the most required skills, salary ranges and how different roles compare.
Built while moving from python basics toward AI engineering

#Why I built it
While people are choosing skills to learn next is guess work, so I wanted the job market's data to answer it

#What it does 
-Reads job postings from `job_dataset.csv`
-Shows the top skills employers ask for
-Shows salary ranges [overall / by role]
-Compares different roles [on what: skills, salary or both]

#How to run it 
1. Clone the repo: `git clone https://github.com/KosaAbbe/Job-Scout.py`
2. Make sure `job_dataset.csv` is in the same folder as `Job_Scout.py`
3. Run:
   `python Job_Scout.py`
4. Describe what the user sees or types next, such as menu, a role name or a prompt

#Known limitations 
the dataset focuses on data analytics/data tech jobs, and the data set is static so it only reflects these postings only
